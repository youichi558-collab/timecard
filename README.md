# 出勤簿 2026

`出勤簿_2026.xlsx` が使う側のファイルです。`出勤簿_2026_original.xlsx` は改修前の元ファイル（保管用）、
`build_timecard.py` は新ファイルを生成するスクリプトです。

## シート構成

| シート | 役割 |
| --- | --- |
| 設定 | 年・氏名・所属・所定労働時間・既定休憩をここで一度だけ入力する |
| 1月〜12月 | 日々の打刻を入力する。集計はシート下部に自動表示 |
| 年間集計 | 12か月分の集計を自動で集めた一覧 |
| 祝日リスト | 2026年の国民の祝日。会社独自の休日も追加できる |

## 入力するところ

黄色いセルだけです。灰色のセルはすべて自動計算なので触りません。

- **出勤 / 退勤** … `9:30` のように入力
- **休憩** … 空欄なら設定シートの既定休憩が自動で引かれる。個別に変えたい日だけ入力
- **通常残業 / 深夜残業 / 早朝残業 / 遅刻・早退** … 時刻形式で入力（実働時間の内数）
- **備考・理由** … プルダウン（有給・欠勤・休日出勤など）から選択、自由入力も可

## 自動でやること

- 日付と曜日は、設定シートの「年」と各シートの月から自動生成。月末日数も自動調整
- 実働 = `退勤 − 出勤 − 休憩`。日をまたぐ勤務（例 22:00〜翌6:00）にも対応
- 祝日名を K 列に自動表示。土曜は青、日曜・祝日はピンクで行を色分け
- 出勤か退勤の片方だけ入力された行はセルが赤くなる（入力漏れの検知）
- 月次集計：出勤日数、実働時間（平日／土曜／日祝の内訳）、各残業、所定超過
- 年間集計シートが 12 か月分を自動で集計

## 改修前からの変更点

- 祝日リストが **2025年のまま** だったので 2026年に差し替えた（元ファイルは 2026年度なのに 2025年の祝日を参照していた）
- 祝日の VLOOKUP 範囲が `$A$2:$C$17` 固定で後半の祝日を拾えていなかったのを `$A$2:$C$40` に拡大
- 勤務時間が「開始〜終了」を並べるだけで計算されていなかったのを、実働の自動計算に変更
- 残業欄が `：` という文字のプレースホルダで集計対象外だったのを、時刻入力＋自動集計に変更
- 「普通出勤時間 = 出勤日数 × 5」という固定計算をやめ、実際の実働から集計するようにした
- 合計 `=SUM(D40:D42)` が普通出勤時間・残業・土曜出勤を足していて二重計上になっていたのを整理
- 氏名を月ごとに入力していたのを、設定シートで一度入力すれば全月に反映されるようにした
- 4月シートだけ明細の開始行が 2 行ずれていたのを、全月そろえた
- 曜日表示を `TEXT(...,"aaa")` から `CHOOSE(WEEKDAY(...))` に変更（Excel の言語設定に依存しないため）
- 印刷設定（A4 縦・横1ページ・見出し行の各ページ繰り返し）と、見出し行の固定を追加

## データ移行について

元ファイルに入力済みだった 1月〜7月の 130 日分は新ファイルに移行済みです。ただし
**3月2日の出勤時刻が `10::00`**（コロンが2つ）と入力されており時刻として読めなかったため、
その日の備考に `要確認: 出勤「10::00」` と入れてあります。正しい時刻を入力し直してください。

## ファイルを作り直す

レイアウトや祝日を変えたいときは `build_timecard.py` を編集して実行します。

```bash
pip install openpyxl
python3 build_timecard.py
```

翌年分を作るときは、スクリプト冒頭の `YEAR` と `HOLIDAYS_2026` を書き換えて実行してください。
