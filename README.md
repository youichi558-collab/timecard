# 出勤簿 2026

`出勤簿_2026.xlsx` が使う側のファイルです。`出勤簿_2026_original.xlsx` は改修前の元ファイル（保管用）、
`build_timecard.py` は元ファイルから新ファイルを作り直すスクリプトです。

見た目は元ファイルのままです。見出し・列幅・フォント（MS PGothic）・罫線・集計欄の位置・列構成
（A〜K列）は一切変えていません。

**12シートの体裁は完全に統一しています。** 元ファイルは月によって微妙に体裁が揃っていませんでした
（4月だけ明細の開始行が2行ずれている、K列の見出しが違う、など）。個別に直すのではなく、1月シート
だけを土台として体裁を整え、それを11か月ぶん複製して作る方式にしたので、12シートはフォント・罫線・
列幅・印刷設定・入力規則まで1文字も違わず統一されています（実際に全セルの書式を突き合わせて確認済み）。
データ（出勤・退勤・理由など）は複製後にシートごと入れ直しています。

```
   A     B   C  |   D     E    F  |   G      H     I     J   |  K
 ┌───── 日付 ─────┐ ┌──── 勤務時間 ────┐ 通常残業 深夜残業 早朝残業 遅刻・早退  理由
    1    日  (木)   1000  ～  1600                                  元日
```

## 入力するところ

- **勤務時間（D・F列）** … **コロンなしで `930` と入力すれば `09:30`** になります。
  `9:30` とコロン付きで入力しても構いません。どちらでも同じ結果です
- **通常残業 / 深夜残業 / 早朝残業 / 遅刻・早退（G〜J列）** … 勤務時間と同じ入力方法
- **理由（K列）** … 祝日名が自動で入ります。手で書き換えればその文字がそのまま残ります

下部の集計欄は自動計算なので触りません。

### 時刻のコロンなし入力について

HHMM（4桁）として読むので、桁を省略しないでください。

| 入れたい時刻 | 入力 | 表示 |
| --- | --- | --- |
| 9時30分 | `930` | `09:30` |
| 16時15分 | `1615` | `16:15` |
| 12時ちょうど | `1200` | `12:00` |

`12` と入力すると 12時ではなく **0時12分** になります。時ちょうどのときも `1200` のように4桁で
入れてください。分に 60 以上の数（`960` など）を入れるとエラーメッセージが出ます。

## 自動でやること

- **理由（K列）** に祝日名を自動表示
- **土曜・日曜・水曜・祝日の行を赤色で塗る**（休日として同じ色でまとめています）。
  水曜が祝日と重なっても、同じ色のまま変わりません
- **集計欄**（元と同じ位置・同じ見出し）
  - 出勤日数 … 出勤時刻が入っている日数
  - 普通出勤時間 … 土曜以外の実働（退勤－出勤）の合計
  - 残業 … 通常＋深夜＋早朝の合計（実働時間の内数）
  - 土曜出勤 … 土曜の実働合計
  - 合計 … 実働の総合計

実働は D・F 列から日をまたぐ勤務（22:00〜翌6:00 など）にも対応して計算されます。休憩を引く欄は
ないので、休憩を除きたい場合は退勤時刻を調整してください（元ファイルにも休憩欄はありませんでした）。

N〜U列は計算用の非表示の作業列です。表には出ず、印刷範囲（A1:K42）にも入りません。

## 改修前からの変更点

- 祝日リストが **2025年のまま** だったので2026年に差し替えた（元ファイルは2026年度なのに
  2025年の祝日を参照しており、祝日名が1つも表示されていなかった）
- 祝日の VLOOKUP 参照範囲が `$A$2:$C$17` 固定で後半の祝日を拾えていなかったのを `$A$2:$C$40` に拡大
- 勤務時間が「開始〜終了」を並べるだけで計算されていなかったのを、実働の自動計算に変更（表には出さず、
  非表示の作業列で計算して集計欄に反映）
- 残業欄が `：` という文字のプレースホルダで集計対象外だったのを、入力＋自動集計に変更
- 「普通出勤時間 = 出勤日数 × 5」という固定計算をやめ、実際の実働から集計するようにした
- 合計 `=SUM(D40:D42)` が普通出勤時間・残業・土曜出勤を足していて残業を二重計上していたのを、
  実働の総合計に変更（残業は実働の内数）
- 時刻をコロンなし（`930`）で入力できるようにした
- 未記入や `㊞` のままだった月の氏名欄を埋めた
- 4月シートだけ K列の見出しが「休憩時間」になっていたので、他の11か月と同じ「理由」にそろえた
- 4月シートの1日目の曜日が数式でなく `(水）` という文字だったのを数式に戻した
- 曜日の表示をロケール非依存の式に変更（開いた環境の言語設定によって曜日が英語表記になるのを防止）
- **12シートの体裁が微妙に揃っていなかった**（4月だけ明細の開始行が2行ずれている、K列見出しの
  文言違いなど）のを、1月シートを複製する方式に切り替えて完全に統一した
- 土曜・日曜・水曜・祝日の行を色分けした（条件付き書式、休日として同じ色でまとめている）

列の並び・列幅・フォント・罫線・集計欄の位置は変えていません。

## データについて

**入社日は2026年4月15日**です（スクリプト冒頭の `HIRE_DATE` で指定）。これより前の日付の
データは使いません。1〜3月シートは時刻入力・K列の注記とも空欄で、祝日名だけ自動表示される
白紙の状態です（元ファイルの1月にあった「入社日」のメモは、実際の入社日と違っていたため削除しました）。

**7月も一旦リセットして空欄にしています**（`RESET_MONTHS = {7}` で指定）。4〜6月・8月以降は
元ファイルに入力済みだったデータをそのまま引き継いでいます。

入社日やリセットする月を変えたいときは、`build_timecard.py` 冒頭の `HIRE_DATE` /
`RESET_MONTHS` を書き換えて実行し直してください。

## ファイルを作り直す

```bash
pip install openpyxl
python3 build_timecard.py
```

翌年分を作るときは、スクリプト冒頭の `YEAR` と `HOLIDAYS_2026` を書き換えて実行してください。
