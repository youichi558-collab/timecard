# 出勤簿 2026

`出勤簿_2026.xlsx` が使う側のファイルです。`出勤簿_2026_original.xlsx` は改修前の元ファイル（保管用）、
`build_timecard.py` は元ファイルから新ファイルを作り直すスクリプトです。

見た目は元ファイルのままです。見出し・列幅・フォント（MS PGothic）・罫線・集計欄の位置は変えていません。
スクリプトが元ファイルを開いて必要な箇所だけ書き換える方式なので、体裁は元と一致します。

## 表の作り

元の A〜K 列はそのまま。右端に **L=休憩** と **M=実働** の2列だけ足しています。

```
   A     B   C  |   D     E    F  |   G      H     I     J   |  K   | L    M
 ┌───── 日付 ─────┐ ┌──── 勤務時間 ────┐ 通常残業 深夜残業 早朝残業 遅刻・早退  理由   休憩  実働
    1    日  (木)   1000  ～  1600                                  元日
```

## 入力するところ

- **勤務時間（D・F列）** … **コロンなしで `930` と入力すれば `09:30`** になります。
  `9:30` とコロン付きで入力しても構いません。どちらでも同じ結果です
- **休憩（L列）** … 休憩を取った日だけ入力。空欄なら0分として計算します
- **通常残業 / 深夜残業 / 早朝残業 / 遅刻・早退（G〜J列）** … 勤務時間と同じ入力方法
- **理由（K列）** … 祝日名が自動で入ります。手で書き換えればその文字がそのまま残ります

M列の実働と、下部の集計欄は自動計算なので触りません。

### 時刻のコロンなし入力について

HHMM（4桁）として読むので、桁を省略しないでください。

| 入れたい時刻 | 入力 | 表示 |
| --- | --- | --- |
| 9時30分 | `930` | `09:30` |
| 16時15分 | `1615` | `16:15` |
| 12時ちょうど | `1200` | `12:00` |
| 休憩30分 | `30` | `00:30` |
| 休憩1時間30分 | `130` | `01:30` |

`12` と入力すると 12時ではなく **0時12分** になります。時ちょうどのときも `1200` のように4桁で
入れてください。分に 60 以上の数（`960` など）を入れるとエラーメッセージが出ます。

## 自動でやること

- **実働（M列）** = `退勤 − 出勤 − 休憩`。日をまたぐ勤務（22:00〜翌6:00 など）にも対応
- **理由（K列）** に祝日名を自動表示
- **集計欄**（元と同じ位置・同じ見出し）
  - 出勤日数 … 出勤時刻が入っている日数
  - 普通出勤時間 … 土曜以外の実働合計
  - 残業 … 通常＋深夜＋早朝の合計（実働時間の内数）
  - 土曜出勤 … 土曜の実働合計
  - 合計 … 実働の総合計

N〜U列は計算用の作業列で、非表示にしてあります。印刷範囲（A1:M42）にも入りません。

## 改修前からの変更点

- 祝日リストが **2025年のまま** だったので2026年に差し替えた（元ファイルは2026年度なのに
  2025年の祝日を参照しており、祝日名が1つも表示されていなかった）
- 祝日の VLOOKUP 参照範囲が `$A$2:$C$17` 固定で後半の祝日を拾えていなかったのを `$A$2:$C$40` に拡大
- 勤務時間が「開始〜終了」を並べるだけで計算されていなかったのを、実働の自動計算に変更（L・M列を追加）
- 残業欄が `：` という文字のプレースホルダで集計対象外だったのを、入力＋自動集計に変更
- 「普通出勤時間 = 出勤日数 × 5」という固定計算をやめ、実際の実働から集計するようにした
- 合計 `=SUM(D40:D42)` が普通出勤時間・残業・土曜出勤を足していて残業を二重計上していたのを、
  実働の総合計に変更（残業は実働の内数）
- 時刻をコロンなし（`930`）で入力できるようにした
- 未記入や `㊞` のままだった月の氏名欄を埋めた
- 4月シートだけ K列の見出しが「休憩時間」になっていたので、他の11か月と同じ「理由」にそろえた
- 4月シートの1日目の曜日が数式でなく `(水）` という文字だったのを数式に戻した
- 1月シートのO列に残っていた不要な数式を削除した

列の並び・列幅・フォント・罫線・集計欄の位置は変えていません。4月シートだけ明細の開始行が
他の月より2行上にありますが、元ファイルどおりのままにしてあります。

## データについて

元ファイルに入力済みだった1月〜7月のデータはそのまま残っています。ただし
**3月2日の出勤時刻が `10::00`**（コロンが2つ）と入力されており時刻として読めなかったため、
その日の理由欄に `要確認: 出勤「10::00」` と入れてあります。正しい時刻を入力し直してください。

## ファイルを作り直す

```bash
pip install openpyxl
python3 build_timecard.py
```

翌年分を作るときは、スクリプト冒頭の `YEAR` と `HOLIDAYS_2026` を書き換えて実行してください。
